Notes for review

Placement: this screen replaces the "Already have an account?" link — it opens from the Preview Dashboard's primary button. New users are one tap from their existing path; returning users no longer need a hidden link.

Recovery semantics (kept honest per design ethos): Restore = full recovery incl. claimed identity → no re-claim, no seed data. Reclaim = identity + group membership only (passphrase proof); personal data & group history need a backup or a co-member re-grant.
