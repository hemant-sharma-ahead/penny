Recommendation

Build this as one continuous page — no tab component in the implementation at all. On web this is a single route rendering three stacked sections with anchor scroll (the "Accounts / Categories / Preview" row at the top of each frame is a scroll-to-anchor jump list, not a tab switcher — no section is ever unmounted). On mobile it's a single `ScrollView` with the same three sections and a `ref`-based scroll-to on the jump chips. This is a direct, literal read of "one continuous screen" — the earlier v2 tab strip should not have existed even for comparison purposes; noted for future rounds.

Verdict: build the three-section single-scroll page above. Category tiles collapsed by default keep the page from feeling long even with 12 categories, since only genuinely undecided or transfer-suggested tiles need a glance.

Cross-platform note: unchanged from prior rounds — apps/mobile/src/features/import/ImportPage.tsx has no Resolve/Preview parity with the current apps/web-react import core yet. Whichever design is approved needs a full mobile port, not a style pass, and should stay tracked in docs/MOBILE_PARITY.md as its own follow-up once the web design is locked.

Optional exploration — not the proposal above
Genuinely different idea, for discussion only

Conversational resolve: Chip walks you through only what's ambiguous

Since you explicitly invited a fresh idea: instead of any list/tile screen at all, Chip (Penny's existing AI advisor) surfaces the import as a short conversation, but only asks about what's actually ambiguous — categories it can't confidently map, the transfer pair, and flagged rows. Everything it's confident about (the 59 ready rows, 4 of 12 categories with obvious matches) is silently applied and just summarized, never asked about. This is not a chatbot replacing the review screen — it's a progressive-disclosure front door: one clear question at a time, plain-language, with the full tile/list view (the primary proposal above) always one tap away behind a "Show full review" link for anyone who wants to see everything at once. Grounded in Penny's "uncluttered, calm, trustworthy" ethos: it reduces a 69-row, 12-category import to roughly 3–4 actual questions for a typical file, with Chip's existing voice and avatar (no new persona to design).

Every quick-reply chip is a real, bounded action (same underlying Map/New/Skip/Transfer verbs as the tile design) — this is a different front door to the same decisions, not a different decision model. A free-text input is included for power users who'd rather type "map Others to Shopping" than tap through chips. Biggest open question if this were pursued: whether "only ask about ambiguous things" ever hides a decision a careful user would have wanted to see — the "Show full review" escape hatch in the header is meant to cover that, but it would need real testing before trusting it as the default for every import.
