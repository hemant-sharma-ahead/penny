Goal card — liquid fills only inside the icon's shape

Built from the actual icon geometry Tabler ships (not an approximation): each icon has a matching "filled" solid variant with the same internal cutouts (the home icon's door, for instance, is a real hole in the shape, not decoration) — clipping that solid version to a bottom-up rectangle reveals exactly that much of the real shape, so the door/roof/shield-tip stay correct at every fill level.

How it works: two layers, same position/size — a dim outline icon underneath (always fully visible, reads as the empty "vessel"), and a solid "filled" icon on top, wrapped in a clipping box that grows from the bottom as the goal's percentage grows. No custom path-masking needed — Tabler already ships both variants pre-built for most icons.
One real constraint: not every one of our 9 goal icons has a "filled" counterpart in the installed set. Shield/emergency, home, car, heart/wedding, plane/vacation, school/education all do. Three don't: beach (retirement), device-laptop (gadget), and target (the generic fallback for an unmatched name). I'd swap those three specifically to the closest available filled icon — umbrella for retirement (fits "beach" thematically), device-mobile for gadget, and flag for the generic fallback (a natural "goal" metaphor, and distinct from the bookmark icon Set Aside already uses) — rather than leave those three goals without the effect.
