2 Combined design — accordion (1) + side-by-side (4) + icons (5)

Collapsed row: chevron + Template N + era + one status icon (parsed/no-match/no-sample), no text pills at all. Expanded: side-by-side regex | sample, both highlighted in one single color (not a different color per field) — that's what makes a capture and its matched value visually identifiable as a pair, without needing a color-to-field legend. The field chips row is gone entirely; it was only there to translate multi-color highlights back into names, which a single consistent highlight color no longer needs. Click the card below to try it, then see the other kind/status states underneath.

2b Chosen — (4) + (5), with two touch-ups
