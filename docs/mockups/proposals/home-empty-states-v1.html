A user who hasn't opened the app for five minutes yet sees a red "Critical" verdict on their finances.

Net-worth hero: replaces the ₹0 headline + blank 180px chart spacer with a single tappable prompt card, same position, same "+ Add account" destination (Accounts) the real hero already routes to via goToAsset('liquid'). No new screen needed — just an early-return branch in GlanceHeader when summary.accountBalances.length === 0 && totalAssets === 0.

Financial health: replaces the graded ring entirely (no ring, no grade, no red) with a neutral "not yet scored" prompt, shown when every component's status is 'no_data' (already a real per-component status the scorer computes — this just also gates the card-level grade/ring on it, rather than only using it for the gray ring-segment color). Tapping opens the same HealthDetailModal Get-Started flow already wired to "add-data" actions.

Money stats card — recommend leaving unchanged. Its '—' /₹0 placeholders are already honest (not fabricated), and it's the one Home widget covering three otherwise-unreachable screens (Insurance, Loans) at once — worth keeping visible even empty, rather than risking it disappearing along with its only route to those screens.

Recommendation: ship both proposed changes (net-worth hero + Financial Health empty state). Both keep the exact same screen position and the exact same navigation destination the real card already has today — this is a state-branch inside the existing components, not a new screen or a new nav path, so Insurance/Loans/Accounts stay reachable exactly as they are now.
