Implementation shape

  • The separate { kind: 'header' } row type in `TransactionsTab.tsx`'s flattened `Row[]` goes away entirely — a day boundary becomes a small dateLabel?: string field on that day's first transaction row instead, rendered as a compact label above the row's own content (not a sibling list item).
  • Full date label, always with year — dateLabel(key) already exists (`lib/date.ts`) and already special-cases "Today"/"Yesterday"; every other day already includes the year ("29 Jul 2026"), so no format change is needed there, just where it renders.
  • The rail's own top segment for that first row starts right below the label rather than at the row's very top — same continuous-line effect, just a few px shorter to make room.
  • Net height cost per day boundary: one small text line (~13px) instead of today's ~40px banded row — meaningfully more transactions fit on screen without losing the "date shown once per day" grouping you wanted kept.
