What changed & why

  • Stayed a drawer, single scroll — nothing hidden behind tabs/pages, no extra clicks (your call).
  • Grouped cards + consistent rows — icon + label + control everywhere; replaces the chip-grid / segmented / row mix.
  • Modules keep the tap-to-toggle icon grid — same interaction as before, now a legible 4-col grid in a card (was a 5-col grid with 9px labels).
  • Wider (300px) for breathing room.
  • Danger zone — Erase-after-fails + Clear-sample isolated in red, away from everyday prefs.

Kept theme/font/privacy as segmented selectors (unchanged behaviour, cleaner framing).
