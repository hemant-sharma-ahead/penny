Fetched addTransactionPage.dart and transactionEntries.dart directly. The goal picker is a real widget class, SelectObjective, built on a shared SelectChips component with allowMultipleSelected: false — a horizontal row of pills, one per goal, plus an implicit "no goal" pill and a trailing "+" pill to create a new goal inline. Each pill's border is tinted with that goal's own colour. Selecting a pill just calls setSelectedObjective(goal.id); tapping a different pill (or the "no goal" one) swaps the selection — true single-select, not a toggle-per-pill. Difference from Cashew: Cashew shows this pill row always (whenever goals exist), with no separate "enable" step — the "no goal" pill inside the row is the off-state. You specifically want it behind a Tags-style icon toggle instead, matching Penny's own convention rather than Cashew's, so that's what's mocked up here — Cashew's row confirms this exact pill-based selector look, just relocated behind a toggle to match the form you already have.

Implementation notes

  • Where the tile lives: ExpenseForm.tsx's existing ExtraCircle row (line ~740) — a new tile between the Receipt and Lent/Borrowed ones. Only the Goal tile skips the type !== 'transfer' guard the other three have.
  • The pill panel reuses the exact visual style already in this file for the Vacation-event tag pills (rounded-full, 2px border, coloured dot, tinted fill when selected) — no new pill component needed, just single-select wiring instead of multi-select.
  • Single-select behaviour: tapping a pill sets selectedGoalId; tapping the already-selected pill again clears it (sets to undefined) — same "tap again to deselect" idiom, no separate "no goal" pill needed in Penny's version since the toggle tile itself is the on/off switch.
  • List indicator: a small ti-target icon (green, matching the goal accent) next to the title in TransactionsTab.tsx's TransactionRow — same row, same styling convention as the existing receipt-paperclip and shared-expense-people icons.
  • "Manage goals" link in the panel header jumps to the Goals tab — lets someone create a goal without leaving the expense flow if none exist yet (mirrors Cashew's inline "+" pill, but as a link to the real Goals screen instead of a nested add-goal dialog, since Penny already has a full GoalForm).
This matches your ask directly: Goal behaves like Tags/Receipt (icon toggle → panel), the panel itself is genuinely Cashew's own pattern (existing-goals-as-pills, single-select), and linked transactions get the same kind of small inline indicator the list already uses for receipts/shared expenses — nothing here invents a new visual language, it composes patterns that already exist in Penny plus the one borrowed from Cashew.
