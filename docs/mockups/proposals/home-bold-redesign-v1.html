Home, redesigned — bold, dark, one committed accent

Went and researched actual current fintech UI direction (see below) instead of inventing another palette. Every previous round was, without realizing it, the exact "copies Stripe's surface without the logic" failure mode the research names directly — light cards, small pastel icon badges, no conviction. This one is dark by default (now the baseline expectation, not a style choice), commits hard to Penny's own green instead of diluting it with five pastel accents, and gives the one number that matters most real typographic weight.

What actually changed, and why:
  • Dark, not light. "Dark mode is now expected by default... apps that force light mode [read as] low-quality and outdated." Every mockup so far was light/cream — that alone made it feel dated regardless of layout.
  • One colour, with conviction, not five soft accents. Brex commits to orange+black in an all-blue category specifically to signal "we're not a bank." Mercury commits to purple + a custom typeface. Penny already has a real point of difference — green, not the standard fintech blue — but I'd been diluting it with a pastel-icon-per-stat treatment that signals nothing. This version puts the whole gradient/glow budget on the one number that matters (net worth) and lets everything else stay quiet and high-contrast.
  • The hero number gets real typographic weight — Bloomberg Terminal's "every pixel is accountable" principle: the figure the user opens the app to see is the single largest, highest-contrast thing on screen, with a sparkline behind it instead of a decorative allocation bar of five thin colour slivers.
  • Fewer, bigger, quieter icons instead of many small boxed pastel badges (the "generic SaaS dashboard" tell called out in the INDmoney critique — "spacing issue with cards took up too much space," "improper visual hierarchy").

Where this leaves things

This is one confident direction, not a menu — deliberately, since presenting more variants after "you're giving me boring options every time" would repeat the exact mistake. It keeps the structural agreement from the last round (no top bar, floating cluster near the thumb, avatar → Settings) and puts real design energy into the part that was actually missing: colour conviction, typographic hierarchy, and a dark-first surface.

If this direction lands, the next real step is applying the same language (dark surface, one hero number per screen, sparkline/data-texture instead of decorative bars, frosted-glass floating cluster) to Portfolio, Expenses, and Goals — each screen gets its own single most-important number treated with this same weight (Portfolio: current value + return; Expenses: this month's spend; Goals: nearest goal's progress), not a repeat of Home's specific layout.
Real constraint worth naming honestly: the gradient hero text and frosted-glass blur are easy in CSS here but need a real check in React Native — gradient text needs react-native-svg's MaskedView/LinearGradient combo (not free), and backdrop blur needs expo-blur (not currently a dependency). Both are buildable, just flagging they're not drop-in like a CSS gradient/blur is. This must also still work in Light and Penny Blue themes per DESIGN_GUIDELINES.md — the same principles (one confident accent, real hierarchy, sparkline texture) apply there, just inverted contrast, not a second unrelated design.
