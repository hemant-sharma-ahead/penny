Design notes & what's reused vs. new

  • Nothing invents a new visual language. The bucket shell, tile shell, paired-comparison card, toggle rows, and modal chrome are pixel-for-pixel the same components already in the app (BucketCard, CategoryTile, MatchedBucket/PossibleBucket's paired tile, SafeModeSettingsPage's ToggleRow, Modal.tsx) — only the copy and data shown are new.
  • Semantic tokens only. Every color used here maps to an existing theme token (--success/--warning/--danger/--info/--neutral/--primary) — no one-off hex values invented for this feature.
  • Centered modals, never bottom sheets. "Scan a date range" and "Map this sender" both render as Modal.tsx's existing centered card with a top-right close × — never a sheet sliding up from the bottom.
  • Back button on every sub-page via the shared header back-chevron — the one deliberate exception is the mid-scan captive progress screen, which locks navigation exactly like CSV-import's own ImportProgressStep (a padlock icon replaces the chevron, with an explicit "back is locked" note) — not an oversight.
  • Cross-platform scope: this is Android-only functionality per the approved plan — no apps/web-react equivalent is proposed (that app is frozen). The one platform state shown for completeness is the iOS/RN-Web "not available" row, which is a small inline explanation, never a dead toggle.
  • Duplicated-capability check: the review queue is the single, consolidated place SMS candidates are resolved — there is deliberately no second "SMS inbox" surface anywhere else in the app; the Settings counters and the Expenses-tab badge are two entry points into the same one queue, not two separate controls doing the same job.
  • Open items, not this mockup's job: the actual native permission dialog copy is OS-owned (Android renders its own system dialog — the syscallout box above is a signpost, not a mockup of that dialog). Implementation specifics (WorkManager/Headless-JS spike, native library choice) are unaffected by anything here — this file is purely the on-screen Penny UI.
