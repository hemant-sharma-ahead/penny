What changed from the last round

  • Icon is always present, never blank. Keyword-matched against the goal name first; if nothing matches, falls back to the plain target mark (Freedom Fund, above) — every goal gets an icon, no exceptions.
  • Icon renders above the wave, not behind it. Layer order is now: card background → wave → icon watermark → text. Wherever the card is, dark surface or filled liquid, the icon sits on top of that background at the same fixed ~16% white opacity — it no longer fades or tints as the waterline rises past it (Goa Trip at 72% still shows a fully crisp plane, not a dimmed one).
  • SIP needed is back — a second, smaller line right under the amount/days-left row, exactly the same conditional logic as today (sipNeeded > 0 — hidden once a goal is fully funded or already overdue, same as the current card).
