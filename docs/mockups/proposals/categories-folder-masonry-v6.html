Categories — true masonry folder packing

Fix 2's 2-column grid still wastes space because CSS grid forces row-pairs to match height — Health (1 row) paired with Financial (2 rows) stretches Health's card and leaves blank space under it. This packs folders into two independent columns instead: each new folder goes into whichever column is currently shorter, so short folders (Health, Sin Goods, Other) stack on top of each other to fill the space next to a tall one (Renovation, Legal) — no forced matching, no gaps.

How it's packed: walk the groups in their normal order, track a running height per column, drop each folder into the shorter column. Same idea as Pinterest-style masonry, done with a simple greedy bin-pack instead of CSS multi-column (which would also reorder into strict top-to-bottom-then- wrap order — this keeps closer to source order). The >12 overflow example stays full width below both columns, same rule as before.
