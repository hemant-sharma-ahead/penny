Open point — where exactly does the market strip live?

Drawn here pinned above the main asset-class tabs, so it's visible on Equity, Fixed Income, Precious Metals, Retirement, and Real Assets alike — since Sensex/Nifty/Gold/Silver/USD-INR aren't Equity-specific, this reads as "portfolio-wide market context," matching roughly where it sat on Home (global, not buried in one asset class). The alternative would be showing it only inside Equity (arguably more relevant there specifically for stocks) — but that hides Gold/Silver's own price context from the Precious Metals tab, which seems worse. Recommend the pinned-above-all-tabs placement as drawn, but flagging it since your message didn't say explicitly which main tab it should live under.

Code-wise: `MarketTicker.tsx`'s `MarqueeTrack` component is replaced by a plain horizontal `ScrollView` of small cards (no more `reanimated` marquee — `useSharedValue`/`withRepeat` and the seamless-loop double-copy trick all go away, simplifying the component); the existing 3-dot → `Modal` + `Toggle` configure flow is unchanged, just re-skinned to match. It moves from `HomePage.tsx` into `PortfolioPage.tsx`, rendered once above the main tab row regardless of which tab is active. The new summary card is a small new component (e.g. `EquitySummaryCard.tsx`) reading the same `totalInvested`/`totalCurrent` math `PortfolioPage.tsx` already computes today, scoped per sub-tab (Stocks vs MF each get their own numbers, not a combined Equity total).
