Categories — folder-grid proposal

Groups with ≤12 categories collapse into a folder tile with a 3×n icon preview — tap an icon to select it directly, same as today, no folder needs to open first. Groups that would overflow the preview (>12 categories) stay exactly as today's full flat grid, so nothing ever costs a second tap.

Rule: per-group category count ≤ 12 → render as a folder tile (icons directly clickable). Category count > 12 → render as today's full-width flat grid (no folder wrapper, no extra tap). All of Penny's current default groups fit under 12 — the fallback only kicks in for a large user-created group, shown on the right as an illustrative example.
