Recommendation and what's still open

Recommendation: Cluster option 1 (merged capsule), used throughout above. It's the only one of the four that keeps all three controls as genuinely independent single-tap targets (unlike option 2's embedded badges) while reading as one deliberate object instead of scattered dots (unlike the previous round's stacked circles) — and it sits naturally on the same line as the title/greeting without needing its own bar or box.

Portfolio now has real content behind every claim from your brief: the Equity tab's sub-tabs (Stocks/Mutual Funds/IPO/News) replace the old separate Stocks and Mutual Funds tabs and fold News in from Home; the benchmark comparison and underperformer callout are shown as they'd look once built (the underlying XIRR/benchmark data plumbing is still real, separate engineering work — this shows the target, not a claim it's already wired up).

Honest technical notes for when this moves to implementation:
  • Gradient hero text needs react-native-svg's MaskedView + LinearGradient; frosted-glass capsule/cards need expo-blur — neither is in the app today, both are addable, neither is free.
  • The sparkline behind each hero number needs real historical data per screen (net worth history, portfolio value history, monthly spend history) — some of this may not be tracked today and would need its own check, same caveat as the benchmark chart.
  • Removing News from Home's Tools grid and Settings' module list, and building the Equity sub-tab consolidation, both touch real navigation/routing code beyond this visual pass.
