Categories — fixing D's wasted space

D (module-tile folders with names) looked good, but pairing an 8-11 item folder next to a 2-3 item folder in a 2-column grid stretches the short card to match — that's the wasted space. Two structural fixes, same data as before, no more forced height-matching between mismatched folders.

Fix 1 — every folder goes full width, single column, with a 6-across mini-grid instead of 3. Each card is exactly as tall as its own content; nothing to stretch against. Simplest fix, but you lose the "two groups side by side" scan.
Fix 2 — groups with ≤6 categories keep the half-width 3-col card (the "scan at a glance" feel); groups with 7+ categories span the full row with a 6-col mini-grid so they finish in 2 rows instead of 3-4. grid-auto-flow: dense backfills any gaps left behind. Only small folders ever pair with each other now, so any residual mismatch is at most one row.
