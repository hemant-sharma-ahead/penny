Cash Flow — one tile per account, or multiple in one tile?

Today's cash-flow card is scoped to just cash/wallet accounts (bank/card accounts already have a clear paper trail, per the existing design note in useExpenseAnalytics.ts) — one card per account. If you have more than one cash/wallet account, you'd see multiple stacked cards. Below: the same idea, merged into a single tile.

Two ways to read "other accounts" — I want to flag both before building:
Option 1 keeps the current scope (cash/wallet only) but merges every such account into one tile instead of one card each — e.g. "Cash Wallet" + a second wallet, both rows in the same card.
Option 2 goes further and extends this equation-row treatment to every account type (savings, current, credit card too) in that same merged tile — which is a bigger change: it overrides the existing "bank/card accounts already have a clear paper trail" reasoning that scoped this to cash/ wallet only in the first place.
Which did you mean — just consolidate the cash/wallet accounts you already have into one tile (Option 1), or show every account's flow here, including bank and credit card (Option 2)?
