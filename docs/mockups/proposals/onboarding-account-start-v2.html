Flow & the scenarios it covers

Preview → Screen A (three cards) → tap → Screen B (segmented tabs, chosen one active; user can switch tabs) → for Restore/Reclaim, a post-step reconciles the handle and, only if needed, shows Screen ④.

Key addition — handle recovery: after Restore/Reclaim the app re-verifies the identity with the server. If the account was deregistered and the old handle is now taken, we keep all restored data + keys and only ask for a new public handle (Screen ④). If the handle is still free, it's re-registered silently and ④ is skipped.
