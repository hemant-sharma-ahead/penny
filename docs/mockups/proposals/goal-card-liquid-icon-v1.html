How the "submerging" effect works
Three stacked layers, bottom to top — the icon sits behind the wave, so wherever the liquid has already risen, the icon is seen faintly through it (tinted, not hidden), and above the waterline it shows plainly against the dark card.

Icon source: keyword match on the goal name, plain fallback

`Goal.icon` already exists in the schema but is only ever set for the 4 life-stage suggestion templates (Education/Home/Marriage/Retirement) — a manually-created goal (most goals) has no icon today, since `GoalForm.tsx` has no icon picker. Rather than add a picker (one more required field on an already-simple form), a small keyword-inference helper picks a sensible icon from the name itself — same idea category auto-suggestion and event auto-tagging already use elsewhere in this app — with `goal.icon` (when a template already set it) always taking priority over the guess.

Notes

  • Opacity/size tuned so it reads at a glance but never competes with the % / name text — worth a final on-device pass to confirm 9% isn't too faint or too present on an actual OLED panel (colours render differently than this browser preview).
  • The wave layer isn't fully opaque (92%) specifically so the "seen through water" tinting works — a fully solid wave would just hide the icon outright below the waterline instead of tinting it.
