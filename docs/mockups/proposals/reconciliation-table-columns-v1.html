A bank icon marks the statement figure, a calculator icon marks Penny's computed one. Universal enough that most people won't even need to be told which is which.

Literally what was asked: the words "Statement"/"Penny" appear once, as tiny labels on the very first row only — every row after that drops them, since the pattern's already set.

My honest read: I'd go with 3 — key in the header only. It's the cleanest reading of "don't mention it in all the rows" — the header carries the explanation exactly once, in the one place a user's eye naturally checks when they're unsure what a column means, and every row underneath stays pure numbers with zero extra ink. Option 1 (icons per row) works too and is arguably even more foolproof since the icon rides right next to the number you're looking at, but it does mean two tiny glyphs on every single row forever, which is a little more visual noise for a fact you only really need to learn once. Option 2 (color-only) is the lightest-weight but riskiest — it depends on the user noticing and remembering an arbitrary color convention, and doesn't hold up well for colorblind users. Option 4 (first-row-only) is a nice idea in principle but reads a little oddly in practice — the very first row looks different from every other row for no reason once you're a few rows down and forget why.
