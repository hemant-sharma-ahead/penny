Recommendation

Build the Primary tab as-is. It satisfies all three of your notes directly — traceable per-account counts that sum to Preview's totals, an explicit rows-vs-transactions headline with the transfer pair called out and visually bracketed, and category resolution folded into each row instead of a standalone section — while staying closest to the Direction B shape you already approved (status grouping in Preview, not account grouping), which keeps "Needs attention" scannable as one list rather than scattered across account sub-groups.

  • Variation Q (Merged Transfer Diagram) is worth adopting if you find the dashed bracket in the Primary tab too visually heavy once there are multiple transfer pairs in a real file — it's more compact, but only shows net amounts, not each row's own description, so a transfer with mismatched descriptions (partial refund, fee-adjusted transfer) would be harder to sanity-check.
  • Variation R (Stat-Bar Density) is the weakest fit today — proportional bars pay off once you have many accounts (10+), but with 3–4 typical accounts per import the chip-box numbers in the Primary tab are just as fast to read and clearer. The account-grouped Preview layout in its second frame is a genuinely different idea worth keeping in mind for a later "group by account" view toggle, but not as the default.

Verdict: ship the Primary tab. Keep Variation Q's diagram in your back pocket for files with several transfer pairs; park Variation R.
