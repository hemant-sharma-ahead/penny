Defaults assumed in this mock — flag if you'd call any differently:
  • New tags default to not set aside — no inline prompt at creation time, you visit Manage Tags when you want to flip one.
  • Set-aside dot shown on Frequent-tag pills in the expense form, so you can see the classification without leaving the form.
  • Manage Tags is sorted by usage count, most-used first — no manual reordering.
  • Event-linked tags (e.g. #goa-trip2026) still appear in Manage Tags and technically *could* be marked Set Aside too, though in practice their group-share already handles exclusion — left available rather than hidden, for consistency.
