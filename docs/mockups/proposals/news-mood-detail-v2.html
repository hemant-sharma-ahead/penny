  • Built the same way as AssetTaxNote.tsx: local open state, tinted background/border derived from a color (here theme.success/warning/danger/neutral per mood skew instead of theme.info), icon + one-line label + chevron row, expandable body below.
  • Lives as the first entry of the scrollable list (FlashList's ListHeaderComponent, right where the filter row used to sit) — it scrolls with the feed instead of pinning as fixed chrome, so it costs zero permanent vertical space once you've scrolled past it.
  • The disclaimer and source attribution move inside the expanded state, same as today, just opt-in instead of always-shown — nothing is dropped, only what's default-visible changes.
  • The "Filters" icon in the tab row stays from the earlier B mockup (opens the Source/Tone/Holding modal) — separate from this note entirely.
