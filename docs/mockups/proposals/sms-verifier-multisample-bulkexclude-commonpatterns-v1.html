1 Multiple samples per template — small pager

The expanded card gets a "Sample 1 of 3 ‹ ›" pager right above the regex|sample grid — only shown when a template actually has more than one saved sample. Cycling it re-highlights the SAME regex against a different real message, so you can confirm one pattern genuinely handles the different real-world variants it's supposed to. Keeps the card exactly as compact as today when there's only one sample (the common case) — no pager row at all in that case.

T1 (2026-08-15 (current era)) Rs\.?\s?(?<amount>[\d,]+\.?\d*)\s+debited…

Pager only appears once a template has 2+ saved samples.

In the template modal, "Test sender / Test message body" becomes a small list of saved samples — click one to make it the active sample being edited/previewed below, remove any with ×, or add a new blank one. Whichever sample is active when you hit Save is what the preview/live-check below reflects, same as today; every sample in the list gets saved when you save the template.

2 Bulk-exclude — checkboxes + action bar

A checkbox column (plus "select all visible" in the header) on the results table — filter to one sender first (already possible today via search or clicking the sender), then check just the specific messages that aren't real transactions. A bar appears above the table once anything's selected, with Exclude selected / Include selected (both always offered, since a selection might mix already-excluded and not-yet-excluded rows) and a Clear-selection escape hatch. Each action calls the same per-message exclude/include already used by a single expanded row's own action today — this is just a faster way to do it 7 times instead of once.

3 Common Patterns — sorted, with an example + usage count

Sorted alphabetically by label (was insertion order). Each entry now also shows a real matched example string (authored for every built-in; optional for a tester's own custom snippet) and "Used in N templates" — a live count of how many templates across every bank actually contain this exact snippet text. Clicking the count opens a popup listing every one of them (bank + T-number + label); clicking a listed template there navigates to that bank and expands that card directly — turning "is this pattern even still used anywhere?" into one click instead of a manual search.
