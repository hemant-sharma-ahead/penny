Expense Import Redesign — full discussion, v1

Consolidated single-file mockup covering the whole docs/plans/csv-expense-import-redesign.md discussion for apps/mobile's CSV/Manual Expense Import — the new Upload → MapColumns → Accounts → Categories → Transactions → Done wizard shape. Five sections below, each grounded in the real, already-implemented screens it adapts or replaces: wizard stage chrome, the Accounts stage (incl. the new card→account merge suggestion), the Categories stage (incl. direction-aware resolution and the counterparty sub-split), the Transactions stage (capped row lists, Skipped bucket, Discard, un-flag duplicates, and the standing kind-picker override), and the IOU lock-open panel ported into ImportCategorizeModal. Every "— decided" / "— confirmed" tag below reflects a resolution from user review; nothing is left open. Mobile-only — apps/web-react is frozen. Proposal only; no app code touched yet.
