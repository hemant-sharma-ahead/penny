Bank Statement Import — full flow, first pass

Every screen the requirements doc (docs/plans/bank-statement-import.md) calls for, in the order you'd actually move through them: add the account row's Import action → pick your bank & confirm column mapping → review (four buckets) → resolve a possible match → bulk-categorize a repeat merchant → record a brand-new one → handle a lone wolf → commit → manage normalization overrides → the post-import balance nudge. This is a structural first pass — happy to refine any individual screen's visual style once the flow itself is right.
