My recommendation: Option A. Option B reuses the events-flag icon's own existing "small dot" pattern, but attaching it to the Import icon implies "tap Import to fix this," which is only sometimes true (the actual fix is often a relink/resolve action in the Ledger, not a fresh import) — a misleading affordance. Option A is honest about what it's reporting (an account-level status, not an action shortcut) and matches the "Safe: ₹X" pill's own visual weight/scale exactly, so it reads as a sibling status chip rather than a decoration on an unrelated button. Tapping it navigates cross-tab to Accounts (navigate('Home', {'{'} screen: 'Accounts' {'}'}), the same pattern ExpensesHeader.tsx already uses for the Safe pill → CashFlow) — the existing Accounts screen's own per-account badges and detail modal take it from there; this pill's only job is "something needs attention, go look."

Text for 2+ accounts: "⚠ 2 accounts" (plural), tapping still goes to the Accounts list rather than picking one arbitrarily.
