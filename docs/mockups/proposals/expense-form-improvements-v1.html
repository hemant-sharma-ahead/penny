Notes

  • #1 reuses the exact same category picker (CategoryPickerModal) and amount logic (AmountInput's grouping/words/calculator) — only the layout container changes, not the underlying fields. Date moves to its own row below (still net shorter than today, since Category no longer needs a row of its own).
  • #2 reuses AccountFormModal.tsx/useAccountForm.ts completely unchanged — the "+" tile just mounts them locally inside ExpenseForm.tsx. The cross-screen refresh (notifyAccountsChanged/useAccountsRefresh) already exists and is already used by Settings → Safe Mode for exactly this kind of "account changed elsewhere" case.
  • #3 is the simplest change of the three — delete the speed-dial state/UI, have the FAB call the existing "open with default type" function directly. No loss of capability: the type switcher already at the top of the form covers what the speed-dial did.
