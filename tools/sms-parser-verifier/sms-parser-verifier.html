Penny — SMS Parser Verifier

Runs the exact same parser Penny's app uses in production (packages/core/src/core/sms-import/smsParser.ts), entirely in your browser. Nothing you paste here is ever transmitted anywhere — there's no server behind this page at all. If a message fails here, it will fail the same way in the real app; use this to find gaps in the pattern library before they show up on a real device.
